Deterministic gate

The floor that cannot move

A pure Python function, no clock, no network, no model on the decision path. Identical input yields byte-identical verdict. Unplug every model and the refusals still fire.

44 tests green
The hard part of autonomy: an agent that can act for you can be tricked into acting against you. Someone emails it pretending to be you, and it just does it. So we built the thing that says no, and made it a copy of your own judgment that the agent cannot argue with.
Honest framing. The deterministic gate is demo-reliable by design. The learned model is a real, running fine-tune, but on a few hundred rows it is noisy, so when it is unsure it abstains and the gate decides. The capability is real, the demo's reliability is engineered, and both are true at once.
